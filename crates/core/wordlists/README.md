# Word lists

`eff_large.txt` is the EFF Large Wordlist for Passphrases (7,776 words,
12.9 bits per word) by the Electronic Frontier Foundation, published under
[CC BY 3.0 US](https://creativecommons.org/licenses/by/3.0/us/) at
https://www.eff.org/deeplinks/2016/07/new-wordlists-random-passphrases.
Only the dice numbers were removed.
